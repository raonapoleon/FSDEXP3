## 🔹 Sub-Experiment 1: Basic Client-Side Routing

**Objective:**  
To implement basic client-side routing in a React Single Page Application.

**Description:**  
This sub-experiment demonstrates the use of `BrowserRouter`, `Routes`, and `Route` components from React Router to navigate between multiple pages such as Home, About, and Contact without reloading the browser.

**Concepts Covered:**
- SPA (Single Page Application)
- Route configuration
- Component-based navigation

## 🔹 Sub-Experiment 2: Navbar-Based Routing

**Objective:**  
To implement routing with a common navigation bar.

**Description:**  
This sub-experiment demonstrates advanced routing by creating a reusable navigation bar with buttons and title-based navigation. Clicking on the navbar title or buttons navigates to Profile and Dashboard pages dynamically.

**Concepts Covered:**
- Reusable Navbar component
- Default routing using `Navigate`
- Layout-based routing

## 🔹 Sub-Experiment 2: Navigation Using Link Component

**Objective:**  
To implement navigation using the `Link` component of React Router.

**Description:**  
This sub-experiment focuses on navigating between pages using the `Link` component instead of traditional anchor tags. Pages such as Profile and Dashboard are created and navigation is handled smoothly without page reload.

**Concepts Covered:**
- `Link` vs `<a>` tag
- Client-side navigation
- Modular component structure
